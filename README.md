# Kömek

Маркетплейс специалистов для мероприятий и дома (Казахстан).

**Kömek** (каз. «помощь») — каталог, где заказчик находит нужного человека:
для тоя и праздника (тамада, ведущие, артисты, танцевальные группы, диджеи,
звук, фото, видео, декор, повара на выезд) и для дома (няни, домработницы,
водители).

## Как это работает

- Каталог открыт всем: анкета, галерея, видео-визитка и описание видны без входа.
- **Контакты специалиста скрыты** до подтверждения. Заказчик отправляет запрос →
  специалист подтверждает → только тогда открываются телефон и соцсети.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript + Tailwind 4
- Supabase (Postgres + Auth + Storage + RLS), локально через `supabase` CLI

## Запуск

```bash
npx supabase start     # поднять локальный Supabase (порты 544xx)
npx supabase db reset  # применить миграции и демо-данные
npm run dev            # dev-сервер (по умолчанию http://localhost:3000)
```

Переменные окружения — в `.env.local`.
